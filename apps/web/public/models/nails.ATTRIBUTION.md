# nails.glb attribution

`nails.glb` is an original, schematic model of the end of a finger, halved along its midline through the nail. It is generated by [`packages/registry/scripts/models/hair-and-nails.ts`](../../../../packages/registry/scripts/models/hair-and-nails.ts) and contains no scanned, traced or third-party anatomy data. Proportions are chosen for legibility, not measured.

The model is dedicated to the public domain under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). Attribution is appreciated but not required:

> OrganUI fingertip and nail schematic model, dedicated to the public domain under CC0 1.0.

The generator script itself is OrganUI code under this repository's MIT license. Rebuild the model with `bun scripts/models/hair-and-nails.ts` from `packages/registry` rather than editing the GLB; the output is deterministic.
