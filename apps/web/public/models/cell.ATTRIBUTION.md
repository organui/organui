# cell.glb attribution

`cell.glb` is an original, schematic model of an animal cell with a quarter cut away to show its organelles. It is generated by [`packages/registry/scripts/models/cell.ts`](../../../../packages/registry/scripts/models/cell.ts) and contains no scanned, traced or third-party data. Organelles are enlarged and spaced for legibility, not measured from micrographs.

The model is dedicated to the public domain under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). Attribution is appreciated but not required:

> OrganUI animal cell schematic model, dedicated to the public domain under CC0 1.0.

The generator script itself is OrganUI code under this repository's MIT license. Rebuild the model with `bun scripts/models/cell.ts` from `packages/registry` rather than editing the GLB; the output is deterministic.
