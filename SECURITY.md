# Security Policy

If you believe you have found a security vulnerability in OrganUI, please
report it privately so it can be fixed before it is disclosed.

Use GitHub's private vulnerability reporting: open the repository's security
tab and click
[Report a vulnerability](https://github.com/organui/organui/security/advisories/new).
Please don't open a public issue.

Fixes ship in the registry at [organui.com](https://organui.com). Installed
components are source in your project, so re-run `shadcn add` for the affected
item to take a fix.
